### Added
- HTML+CSS export (`emit_html` in `fd-core`): Generates a standalone responsive HTML page with positioned `div`s for shapes/frames and an `svg` overlay for paths, ellipses, and edges. CSS translates layout constraints and styling (fill, stroke, opacity, shadows, rounded corners). This implements requirement R3.56.
